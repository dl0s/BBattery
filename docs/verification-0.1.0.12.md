## 真实失败与修复

0.1.0.10 的设备日志任务 `effaa6d73daf43f2bb0108a767cf7463` 证明 main.qml 第 20 行缺少菜单动作逗号，第 60 行的布局对象后存在错误分号，导致 fallback 加载失败页。0.1.0.11 修复，并增加原生 SDK QML 加载门槛；用户确认首页正常。

0.1.0.11 关闭卡片后普通 QProcess 采集子进程消失。读取任务 `33ce2239f94241c382cd5952324802ac` 保存了仅一个样本、仍为 running 的测试记录，未伪造完成。0.1.0.12 改为应用内注册的 BB10 headless 入口，复用原 batteryd、现有进程锁和数据；服务系统事件循环与采集工作线程独立。原中断记录保留，重启按既有 collector-restart 规则处理。没有修改固件或 btool、使用直接 SSH/SCP、替换凭据、增加开机过滤器或额外监护进程。

构建准备时的错误（libcpp 路径、PowerShell 哈希模块、SDK 旧 Python 与多 Python 解析）及下载目标父目录缺失均保留原任务。修正输入后使用新任务，没有自动重放旧设备变更。
